## Explicit limits of the evidence

- Automated browser flows mock the generation HTTP boundary. Handler tests separately exercise HTTP validation and mocked provider streams; adapter tests verify SDK wiring. These are not live Google calls.
- Schema validation proves structure and arithmetic, not cultural accuracy, supplier availability or factual correctness of every recommendation.
- axe checks do not substitute for a full assistive-technology audit.
- The documented WAF rule is not active until an owner configures and publishes it on a deployed project.
- Repository size refers to source file content, not installed dependencies. The script reports tracked bytes separately from untracked source candidates.
